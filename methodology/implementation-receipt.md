## Proof Boundaries

- Structure pass proves declared schema, type, hash, reference, lineage, and coverage
  integrity only.
- Readiness pass proves the declared artifacts and required checks are complete enough
  for handoff, not that their factual content is true.
- The semantic receipt covers only its named fixtures and model runs.
- Fresh-agent isolation is an artifact allowlist, not host filesystem attestation.
- Output-token counts are serialized-artifact proxies, not model billing telemetry.
- Resource measurements are local synthetic probes, not universal platform guarantees.
- Optional methodology citations explain design choices and are not runtime dependencies.
