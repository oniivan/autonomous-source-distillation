# Methodology Provenance

These files preserve the source-linked research used to deepen Autonomous Source
Distillation on 2026-07-18:

- `report.md`: conclusions, design decisions, limitations, and implementation mapping.
- `citation-registry.md`: primary academic and official technical sources.
- `evidence-ledger.md`: source groups mapped to design implications.
- `claim-ledger.md`: atomic methodology claims and their support.
- `emerging-technique-registry.md`: adopted, conditional, pilot, and rejected methods.

This directory is explanatory provenance. The installable skill is self-contained in
the repository root and does not require these files at runtime.
